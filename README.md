# 2D Platformer C#

A 2D Platformer game engine & mechanics prototype built with C# and .NET 8, featuring player physics, collision detection, gravity, and level management.

## 🎮 Game Features

- **Player Physics**: Acceleration, velocity, gravity, and jumping mechanics.
- **Bounding Box Collision**: AABB collision detection against platform tiles.
- **Score & Level Manager**: Level loading and score tracking.

## 🛠️ Tech Stack

- **Language**: C# 12 / .NET 8
- **Architecture**: Entity-Component Game Loop

## 🚀 How to Run

```bash
dotnet build
dotnet run
```
